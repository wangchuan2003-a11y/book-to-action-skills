# 选书与来源标准

研究日期：2026-09-07。当前版本是问题导向的首批选集，覆盖范围仍会扩展。

## 为什么选这些书

不合成虚假的“全球 Top 100”分数。一本书进入正式书库，应有明确的方法用途、可核实的一手或学术来源、可解释的边界，以及与已选书的互补价值。经典地位可以支持编辑选择，但不能自动支持书中事实。

首批包括当代方法书和中西经典。它偏向能够转化为行动的非虚构作品，不代表文学、诗歌、宗教、数学和世界思想传统的完整地图，也不把英语出版市场当作整个世界。

## 证据层次

1. **作品原文或合法摘录**：支持“作者在这里怎么说”，范围限于实际读过的章、节或摘录。
2. **作者、出版社或学术机构的说明**：可支持书目与方法归属；简介和营销评价不支持效果承诺。
3. **独立研究**：只支持研究真正测量的对象与结果，不把实验室效果直接推广为工作绩效。
4. **本项目的迁移推断**：明确标识为应用设计或待验证假设，不冒充作者对当代事件的判断。

所有留用来源记录 URL、访问日期、种类、已读覆盖、支持内容与局限。检索摘要不算正文；被阻断的正文必须写明不可核实，换用足够来源或降低结论强度。相同材料的转载不算独立证据。

## 单书交付合同

- `SKILL.md`：准确的触发范围、具体方法、所需输入、产出、适用边界，按需链接参考文件。
- `book.json`：书目、入选理由和来源记录。年份可以用字符串表达古典作品年代的不确定性。
- `references/source-notes.md`：概念与来源/章节对应，证据缺口，不伪造页码。
- `references/worked-example.md`：原创案例、推理、可观察结果、反例。
- `evals/cases.json`：正常应用、范围边界和对抗/缺证据案例；使用可观察行为标准，不以固定措辞作正确性标准。
- `agents/openai.yaml`：简短说明与显式调用示例。

每本 Skill 自包含，不依赖个人电子书路径、账号、付费 API 或本项目之外的 Skill。需要原文精读时要求真实文本，不在没有原文时承诺覆盖全书。

## 迭代方式

先补缺失证据，再修改方法。每轮留下版本差异和验证结果。只有观察到真实失败，才增加针对性的约束；不能靠堆文件、堆题目或自评高分宣称质量变好。
