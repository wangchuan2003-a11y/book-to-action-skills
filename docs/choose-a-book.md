# 从问题选择一本书

先确定你需要完成的判断，再选择一种主方法；遇到该方法解决不了的具体缺口，再引入第二本。多个框架同时铺开会掩盖最重要的工作。

## 事实、因果和预测是不同任务

- “这些理由足以支持结论吗？”用《人类理解研究》区分观察、推断与归纳边界。
- “改变X是否会让Y改变？”用《为什么》明确干预、因果假设和可识别条件。
- “这件事在期限前会发生吗？”用《超预测》留下参照类、概率和结算记录。

例如：使用AI的人分数更高，是相关观察；随机分配辅导方案并比较结果，可以帮助估计特定干预效果；预测下一批用户有多少会坚持，是另一件事。不能用其中一个答案自动代替另外两个。

## 重复救火先看机制，再决定资源

《系统之美》帮助解释反馈和延迟；《好战略，坏战略》帮助从已识别的障碍中作取舍；《公共事物的治理之道》进一步检查共同资源的规则、参与和纠错。

“工单不断积压”先建立流入、流出与返工的小模型。“两个人做五条产品线”进一步需要选择核心障碍。“大家争抢GPU”则还涉及谁能制定和调整分配规则。这些书互补，不能相互取代。

## 学习与解决题目不要混为一谈

需要完成当前题目，用《怎样解题》；需要之后独立解出同类与陌生题，用《认知天性》；需要选择值得研究、又有可行突破路径的问题，用《科学与工程的艺术》。

用户明确要求答案时先回答。练习和迁移可以作为后续选择，不能为了教学拖延交付。AI答对了、答案很流畅，都不证明用户已经学会。

## 标准化、分工与人的处境

《国富论》关注专业化如何产生收益，以及市场规模怎样限制分工；《国家的视角》检查可测量规则遗漏了哪些当地知识；《资本论》提供另一套分析劳动、资本与剩余的概念。

例如，把审批拆给十个人，要检查专业收益与等待成本；只按工单数量考核，要检查复杂工作是否被隐藏；讨论劳动关系，要区分理论术语、可测量数据、价值判断和法律结论。不要从任何一本直接推出某种现实制度必然正确。

## 伦理观点需要保留分歧

《论自由》帮助讨论限制行为的理由与范围；《尼各马可伦理学》关注情境中的恰当判断；《论语》提供角色、学习与修养的思想资源。它们不共享所有前提，也没有一个把答案简单平均的总公式。

先说明实际冲突、谁受影响、已知事实和价值选择，再使用最相关的观点。古人的一句话不能替代对当下责任和后果的判断。

## 原文、文学和版本

需要引语、页码或细读时，以实际提供的版本和片段为准。Skills的来源说明能告诉你已经核读什么，也会说明没有核读什么。书目页和目录不能替代正文。

小说适合练习人物动机、叙述视角、语言与多种解释之间的比较；人物的话不等于作者立场，也不必被压缩成生活戒律。只讨论用户已读或主动授权的情节范围。

## 数学、程序与自然现象

《几何原本》帮助区分定义、假设、作图与证明；SICP检查过程、求值和抽象边界；《费曼物理学讲义》进一步要求模型、单位与观测相互对应。《算法之美》把计算方法用于决策时，还要核查问题是否满足算法假设。

一道公式推导正确，不意味着自然界满足其假设；一段递归程序的定义短，不代表运行过程短；一个停止规则在随机候选模型里最优，也不代表现实排序下最优。
