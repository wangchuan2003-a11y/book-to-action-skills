# 先问波动改变谁的什么结果

取得对象、扰动、时间范围、希望改善的结果、成本承担者，以及不可接受的损失。不能只因一个人或系统经历困难后仍存在，就称其反脆弱。

## 五个动作

1. **区分三种反应。** 脆弱是相关扰动令结果恶化；稳健是基本维持；反脆弱是在明确范围与条件下从扰动获益。说明是期望收益、长期表现还是已观察结果，不混用。
2. **比较损益曲线。** 检查轻微与较大扰动造成的影响，是否存在阈值、连锁失效或尾部损失。仅说“失败能学习”没有计入失败代价，也没有证明反应为凸。
3. **先保住继续试的能力。** 检查一次失败及累计失败是否会耗尽基本生活、关键服务或项目资源。并行小试验若共用同一个脆弱依赖，仍可能一起失败；不能把损失转嫁给别人后声称自身无风险。
4. **设计真实选择权。** 在小范围内试，预先知道最多花多少、何时结束、怎样保留有用结果以及能否退出。选择权有获取和维持成本；做得多并不必然更好，试验之间也未必独立。
5. **用结果而非标签迭代。** 记录收益、损失、退出成本和负结果，比较波动前后及相应基线。没有数据就称“有利损益结构的候选设计”，不直接认证反脆弱或保证赚钱。

## 输出

对象与扰动范围 → 损益与不可承受损失 → 备选结构 → 最小试验及停止条件 → 还不能证明的部分。预算与数量从任务给定约束取得；缺失时写建议上限，不冒充授权。

凸性论证依赖变量、适用区间、分布变化和成本条件，不是“凡随机就更好”。局部正期望也不保证每次获利或避免破产。金融、医学、工程安全的具体决定须按相应证据处理，不从作者类比直接推治疗、训练或杠杆比例。
