# 以自由看待发展：从给了什么转向真正能做什么

审查一项方案是否扩展了人们真实可选择的生活机会。当前证据为SEP对能力框架的学术解读及书目；没有读到本书原文，因此不声称覆盖所有章节、五类工具性自由或作者全部论证。

## 五项区分

1. **资源、已实现状态、可行机会。** 资源是钱、设备、服务等手段；functionings是已经做到或达到的状态；capabilities指真实有可能选择实现这些状态的机会。领取设备、参加课程、获得收入和真正能使用这些资源不是同一指标。
2. **正式可用与实际可达。** 检查时间、交通、身体条件、语言、照护责任、制度和环境怎样促进或阻碍资源转化。依据用户提供或可查材料分析，不擅自推断个人敏感特征。
3. **实现与自由选择。** 没有做某件事可能是自愿选择，也可能是没有真实机会；只凭完成率无法区分。反之，强迫所有人完成同一任务可能提高结果数字，却没有相应扩大选择。
4. **福祉与能动性。** 人可能重视并不直接增加个人收入或舒适的目标。让受影响者说明他们有理由重视什么，保留拒绝、表达和修改方案的机会；不能替他们规定唯一理想生活。
5. **维度、取舍与证据。** 先明确本问题重视哪些机会、谁参与选择和权重依据，再比较方案。收入仍可能是关键手段，不能因采用能力框架便删掉财务约束。不要把多个维度未经说明揉成一个客观总分。

## 交付

用一条清楚主线回应：“目标机会 → 资源 → 转换障碍 → 可选干预 → 怎样检验”。至少区分提供量、实际实现和选择空间；在用户授权范围内提出可观察的小验证。数据没有区分自愿不参加与被阻挡时，结论应保留不确定性。

能力框架含规范承诺，也有维度选择、测量与聚合的争论。Sen、Nussbaum及后继研究者并非同一种完整理论；不能把Nussbaum的清单当Sen固定标准，或声称一套指标能给所有社会唯一排名。本Skill不保证某政策、教育方案或经济干预必然成功。
