# 原创案例：发了免费课程，机会就平等了吗

某项目向100名参与者提供同样的免费课程账户，负责人想据此宣布“每个人获得了相同学习机会”。以下为教学设定，没有真实项目数据。

账户属于资源。学完课程、完成一次实际任务属于已实现结果。能够在合理条件下选择并完成学习，是另一层真实机会。三个层次不能互换。

现有记录显示有些参与者只有低性能手机，有些需要照护家人，课程又只在固定晚间直播；这些是题目给定事实，不是从性别、年龄或收入标签推断出来的特征。即使账户相同，设备、时间和课程形式可能导致可达机会不同。

先区分未参加的原因：没有兴趣而自愿不学、希望学但时间不允许、设备打不开、看不懂材料，分别需要不同回应。不能把所有缺席都称为懒惰，也不能把所有缺席都称为剥夺。

候选改进包括轻量内容、回放、不同时间安排或必要设备支持。应由实际障碍和当事人意见决定优先级，预算仍然需要核算；没有证据说明哪一项对所有人最好。

观察三个层次：账户能否访问；愿意学习者能否完成目标任务；参与者是否有可行的时间/形式选择并能拒绝不需要的课程。满意度和完成率可以补充，不能单独代表能力集合。

如果强制每日打卡使完成率上升，却让照护者不得不牺牲必要生活安排，不能仅凭高完成率宣布自由扩大。反之，有人具备真实机会但选择其他有价值目标，也不能自动判项目失败或个人没有能力。

这些指标与改进是原创应用设计，不是Sen给本项目设定的官方清单；一次试行也不能证明长期就业或发展效果。
