# 原创案例：基准高分是否意味着范式革命

某团队把规则程序换成语言模型，固定问答集准确率从70%升到90%，于是宣称“知识评价的范式已经革命，旧测试全部作废”。这些数字是本案例的虚构设定。

首先，高分支持“在这个问答集上有提升”。若问题、标签、评分标准都没变，单看这项证据主要体现同一评价框架内的性能改进。模型结构不同当然可能重要，但不同结构本身不完成科学革命的论证。

现在加入一项异常：模型在新来源文档上给出表面流畅但无法核对的答案。需要排查训练集污染、数据分布变化、评分规则漏项和随机波动，不能直接把一个失败叫成学科危机。

如果团队提出把“唯一标准答案匹配”改为“来源支持、条件限定、可复核推理”的评价标准，变化涉及怎样定义好答案。比较时需要说明新标准多解决了什么，以及标注一致性、成本和旧测试可比性损失了什么。这仍是AI评估方法变化；是否值得称作库恩意义的科学革命，需要更广的学科与历史证据。

下一步可以在同一份未见样本上同时执行两套评分，公开分歧类型和人工复核规则。该动作检验新标准的用途，不用一次试验决定一个宏大的历史标签。

反例：换一个更快的数据库，但概念、任务和判断标准保持不变，不应仅凭速度提升宣布范式革命。
