# 原创讲解：在非零线段上构造等边三角形

给定现代欧氏平面中不同的两点A、B，设距离为a>0。以A、B为圆心各作半径a的圆，取一个交点C，再连接AC、BC。

先说明C存在：两圆半径相同，圆心距为a，满足`0=|a-a|<a<2a`。在采用的现代欧氏平面及相应连续性背景下，两圆有两个交点，任取其一。这个背景补充必须明确，不能仅指着图说“显然相交”。

接着证明所需性质：C在A圆上，所以AC=AB=a；C在B圆上，所以BC=BA=a。因此三边相等，得到等边三角形。C不在AB直线上，故不是退化三角形。

可用坐标给一条独立核对：令A=(0,0)、B=(a,0)，C=(a/2,√3a/2)，则AC²=BC²=a²。这个一般代数核对使用现代坐标体系，不冒充Euclid的原证明。

## 两个反例

如果A=B，则a=0，两圆构造退化，不产生通常定义中的三角形。不能因为三条“边”都是0便宣布构造成功。

如果只知道任意两圆半径和大于圆心距，也不能保证相交。r1=5、r2=1、d=1满足6>1，却有d<|5-1|；小圆完全位于大圆内部。故构造前必须检查完整条件。

## 验证的限度

画100张图或检验100组坐标可以发现错误，不能替代对任意a>0的推导。这个证明也不自动确定大型宇宙尺度的空间几何；后一个问题需要物理模型与观测。
