# 原创案例：上级要求隐去坏消息

用户主动希望用《薄伽梵歌》反思：上级要求报告只展示成功案例，说“尽好你的职责，不要纠结结果”；用户既担心失去工作，也担心误导客户。

先重建责任：对上级有合理协作义务，对客户有准确说明的责任，对事实和适用规则也有约束。上级的一句话不能自动定义全部dharma，更不能把自己放到经文中Krishna的位置。

2.47可以帮助区分“做好有依据的报告”和“必须确保所有人满意”的执著。它不能直接消除隐瞒带来的后果。这里应查明报告用途、失败样本是否影响结论，以及是否存在误导性遗漏；不要只凭情绪判断。

借18.63的审思线索，比较三种做法：直接隐去、完整说明、用主报告加明确限制/附录的方式准确呈现。哪种可行取决于真实材料和规则，不能提前保证第三种一定解决冲突。

下一步可先拟一份保留关键事实且表达清楚的报告草稿，并写明遗漏哪些结果会导致误读；如何沟通依当前授权进行。反馈看信息是否准确传达、是否仍有误导风险，而不是仅看上级是否高兴。

“结果不完全由我决定”不代表不再修正报告，也不代表必须接受欺骗或虐待。该分析是现代伦理应用，不是对全部注疏的裁决；没有向第三方发送任何材料。

反例：用户只问2.47某个词怎样翻译，应围绕词义、所用译本和上下文回答，不擅自做职业辅导或要求接受宗教信仰。
