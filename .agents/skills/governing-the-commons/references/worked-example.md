# 原创案例：灌溉渠道的“先到先取”

假设一个灌溉小组有四块农田，面积分别为2、2、4、2公顷，共用一条渠道。仅为教学，假定当地合法评估已确认当前每天可分配水量为100立方米。上游先取水，下游经常没有足量水；维护主要由下游承担。没有给出作物需水、渠道损耗和既有水权。

## 诊断

水是会被取用减损的资源，渠道是资源系统；土地共同或分别所有，不能回答水如何治理。当前规则是事实上的先到先取，存在上游位置优势和维护收益错配。“大家都自觉一点”没有改变这些机制。

先记录合法使用者、现有取水权、到田水量和渠道损耗，并核对四块田的作物、时段和供水需求。按面积20/20/40/20立方米分配只是一种候选：它依赖单位面积需水相近等假设，不能先叫作公平方案。

## 一项可讨论的规则草案

在现有水权允许的范围内，四方及受影响的其他权利人共同确认轮灌次序、额度、紧急例外与修改方式。每次实际取水和资源状态留简明可查看记录，监测者由使用者认可并可被问责。维护责任与使用收益如何相配，需要明确讨论。

第一次可纠正的超取先核对测量和原因，要求补救；重复违反已同意规则才按合法规则渐进处理。争议可以提交成本较低的现场核对或调解；不能让同一个受益方既判违规又决定处罚。

以一个合适灌溉周期试行，实际长度由作物和供水周期确定。观察下游未获水次数、各方实际供水与需求、维护投入及争议处理成本。这里没有实测结果，也不声称已提升公平或产量。

## 反证与外部影响

若主要原因是渠道泄漏或可供水量估计错误，仅改排队规则不足；若区域旱情使总量下降，必须重新协商并与更大流域协调，不能让小组凭自己的规则侵害下游外部权利人。

反例：一份任何人都能复制的公开文档，读取一般不会减少别人的文本。若问题是编辑维护不足，应分析贡献、审核时间和服务器成本，不能照搬限水额度处罚读者。
