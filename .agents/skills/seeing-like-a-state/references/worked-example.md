# 原创案例：把所有上门服务压成30分钟

某服务公司拟统一规定：每单30分钟内关闭，每人每天关闭8单；超时一律判绩效差。已知各片区交通距离不同，服务事项难度也不同，现有表格只记录开始与关闭时间。尚无证据说明超时主要来自拖延。

## 管理收益与遗漏

统一工单编号和时间记录有助于派单、客户追踪和发现拥堵，这些收益应保留。但单一时长遗漏了路程、备件等待、问题复杂度、重复处理和真正解决情况。表格简洁不证明任务同质。

如果直接把时长绑定处罚，可能诱发提前闭单、回避复杂任务或把一单拆成多单。它们是需要查证的预测，不是已经观察到的违规事实。替代解释包括排班不合理、备件短缺和技能差异。

## 最小修补

保留共同标识与时间戳，补少量能改变解释的原因分类和备注；选取跨片区真实案例，与执行者和客户记录对照。区分“客户问题解决”与“系统状态已关闭”。复杂任务可以进入可核对的例外审查，不能仅凭个人声称“我有经验”就免于问责。

先在一个可代表不同任务类型的小范围试行：同时观察解决时间、同类问题重开、客户是否确认解决及填写记录的额外负担。不要在记录机制尚未验证时立即把所有新指标绑定奖惩。试行窗口和可接受阈值由实际业务节奏确定。

若补充分类也不能解释差异，且观察证实某步骤长期低效，应改进该步骤，而不是继续把所有问题归因于“上面不懂”。若统一标识显著改善协作且未发现重要信息损失，应保留它。

## 反例

紧急救援中的统一地址或道路编号，可以消除同名地方造成的歧义。用Scott反对所有编号，会丢掉作者本人示例中的收益。需要评估的是标准承担什么任务、是否补得上本地知识，以及谁能纠正错误。

本例为原创审查，没有实际观察公司，没有实施系统修改，也没有证明试行后的绩效改善。
