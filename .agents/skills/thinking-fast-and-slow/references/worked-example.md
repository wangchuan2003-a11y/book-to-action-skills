# 原创案例：90%检出率意味着告警九成是真的？

教学设定：故障率2%，告警对故障的检出率90%，对正常设备的误报率10%。有人看到一条告警便说“故障概率90%”。

真正问题是“在已告警条件下有多少是真故障”，并非“已故障时多容易告警”。

将同样条件展开为10000台假想设备：

- 200台故障，其中180台告警。
- 9800台正常，其中980台误报。
- 1160条告警中180条来自故障，比例约15.5%。

这些都是由演示前提推导的期望数量，不是实际监测记录。结论依赖故障率、检出率和误报率可用于同一目标环境；条件改变就需重估。

可以据此分级复核告警，而不是直接全部忽略或全部停机。具体操作仍取决于漏报代价和真实维护规则。

反例：“得出15.5%说明我打开了系统2脑区。”这只是使用分母完成了计算，没有测量脑活动，也不证明以后都不会犯相同错误。
