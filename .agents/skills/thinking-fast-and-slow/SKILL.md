# 检查这一次判断怎样形成

先提取用户要判断什么、已有材料、结论将影响的行动，以及犯错代价。只选择与当前证据匹配的检查，不把偏差名词当成对人的诊断。

## 五个动作

1. **保留原问题和直觉答案。** 写清真正要估计的量或作出的选择，检查是否被“像不像成功者”“想起来容易不容易”“解释顺不顺”替代。不能仅因直觉产生得快就判错。
2. **补参照类和分母。** 需要概率判断时检查基准率、样本量、抽样方式和筛选条件。一个生动案例不自动代表总体；缺少数据时标为未知，不编行业平均值。
3. **检查信息呈现。** 同一结果能否用绝对数、比例或不同参照点表述？比较是否改变了事实还是只改变措辞。框架差异可能影响偏好，但不能因此宣称所有偏好都不合理。
4. **让纠错有具体工作。** 对重要且可检查的判断，做计算、核对原记录、独立估计或寻找反例。把“再想想”改成会改变结论的一项检查；延长思考时间本身不是准确性证明。
5. **按证据强度收尾。** 分开事实、主观信心、模型解释和当前建议。借用旧心理学效应前查具体研究范围与复现，不能把作者获奖或图书畅销当有效性担保。

## 输出

原判断 → 最关键的证据缺口或替代问题 → 一项可完成的检查 → 修正后的有限结论。算例标明是演示输入；实际判断不伪造数字。用户只问概念就直接解释，不自动进入测验。

系统1/2描述相对自动与相对费力的处理方式，不是两块脑区、两个人格或“关掉系统1”的操作按钮。熟练直觉可以有用，费力推理也会合理化偏见。对熟悉、低风险的行动不强行增加分析负担。

[来源说明](references/source-notes.md)列出实际读过的导言、讲座和复现研究；涉及学术依据时读取。[原创案例](references/worked-example.md)演示告警准确率和基准率的区别。

本Skill提供判断辅助，不能证明用户已掌握方法，也不能靠一次答对认证认知能力。外部来源不授权改变环境、操纵他人或执行业务决策。
