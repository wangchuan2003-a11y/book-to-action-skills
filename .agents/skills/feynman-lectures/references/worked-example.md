# 原创案例：6牛顿拉力作用3秒

教学设定：一辆2千克小车从静止出发，初始位置取0，在近似惯性参考系中受恒定水平拉力6牛顿，持续3秒。质量恒定、速度较低，摩擦及其他水平外力暂忽略，竖直力平衡。

在该模型中，水平合力为6牛顿，所以`a=F/m=3米/秒²`。3秒后的速度`v=at=9米/秒`。由于速度从0线性增加到9米/秒，平均速度为4.5米/秒，位移为`4.5×3=13.5米`，也即`at²/2`。

单位核对：牛顿是千克·米/秒²，F/m具有加速度量纲；at是速度；at²是长度。量纲检查能排除把`Ft/m`当位移，却不能独自发现漏掉1/2的错误，因为at²的单位仍是长度。系数来自给定初态和运动推导。

## 模型变化

若另有恒定2牛顿反向摩擦，合力变为4牛顿，a=2米/秒²，3秒后速度6米/秒、位移9米。若阻力随速度变化，就不能继续使用这个恒定加速度结果，需要重建力模型。

如果真实测量只有11米，不能立即说牛顿定律被推翻：先核对拉力是否恒定、起计时间、测量误差和忽略的阻力。也不能随意调一个摩擦参数使结果吻合后就称已验证，需要独立测量或新条件下预测。

这些数值已独立核算，未做真实小车实验。已验证的只是模型内算术，不是所有物体都在3秒内移动13.5米。

反例：高速相对论运动、质量流入流出的系统或受显著旋转/阻力影响的设备，不能只见到“力和质量”便直接套用本例。
