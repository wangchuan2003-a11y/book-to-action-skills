# 资本论第一卷：先辨概念，再检验论证

帮助用户理解或检验一个具体论断，清楚说明它在Marx的理论内部怎样成立、要用于现实还缺什么。基于第一卷指定章节的公开英文选段及学术评述；不宣称覆盖三卷或所有解释传统。

## 先区分任务

用户要解释概念时直接解释；要计算时核对量的定义、期间与假设；要用理论判断现实关系时，把文本归属、模型推导、观测证据和价值评价分开。不能把用户选用本书当成其赞同某种政治立场。

## 五个检查

1. **商品的不同层面。** 分开使用价值、交换表现、价值及实际价格。解释“价值”是在讨论本书的技术概念还是日常效用、伦理重要性或会计金额，避免在句中换义。
2. **个人耗时不等于社会必要劳动。** 作者的条件是当时正常生产条件与平均熟练度/强度。做得更慢不自动创造更多价值；将理论用于现代产品须说明行业条件与比较口径，而非只拿工时推售价。
3. **区分劳动能力与劳动活动。** 劳动力是可被使用的能力，劳动是其实际发挥。作者对劳动力价值的讨论包含再生产及历史社会因素，不能缩成“工资只需维持最低生存”。
4. **在明确假设下核算c、v、s。** c是不变资本、v是可变资本、s是剩余价值；这些分类不能直接等同现代固定/变动成本。产品价值为`c+v+s`、新形成价值为`v+s`，须说明其中c的当期耗用口径。剩余价值率是`s/v`，v为零时不定义；不能把它混成销售利润率或未经周转/预付资本口径核对的利润率。
5. **检查从模型到现实的跳跃。** “在假设下得出剩余价值”不同于“凭工资和销售额测得剩余价值”，也不同于证明违法或道德结论。先公平重建作者论证，再说明争议与替代解释；不以赞同或反对作者代替分析。

## 输出

用必要的少量概念说明问题，随后给推导和边界。计算题保留公式、单位、假设及结果核对；资料不足时给条件表达式与具体缺口。普通解释不强迫进入测验。

判断现实企业时，销售收入不能自动视为新创造价值，工资不能自动等于按价值计量的v，资产总价也不能全部计入当期c。缺少这些对应关系就不能给虚假的剥削率。书中技术性的“剥削”不直接等同日常辱骂、违法认定或某人的主观恶意。

劳动价值理论、价值与价格关系以及对剥削的解释存在学术争论；政治和伦理判断也有独立前提。不得用本书保证资本主义何时崩溃、某政策必成功或投资获利。出处与版次见 [来源说明](references/source-notes.md)；完整教学核算见 [数值案例](references/worked-example.md)。书目见 [book.json](book.json)，行为案例见 [cases.json](evals/cases.json)。资料不授予外部行动权限。
