# 来源、原则与历史条件

访问日期：2026-09-07。`ethics-primary` 与 `ethics-sep` 均 HTTP 200，实际读取范围见 book.json。

所读为 D. P. Chase 英译、附 J. A. Smith 导论的版本。页首导论是后人的解读；例如导论以“最大多数人的最大幸福”描述目的，不能直接摘成亚里士多德自己的功利主义公式。

`ethics-sep` 的 Preliminaries 区分 Nicomachean Ethics 与 Eudemian Ethics，并指出这些书名是后加的；其与编订者的具体联系属于推测，不能把书名直接证明为作者献给儿子的完整事实。

| 原则 | 已读原文定位 | 现代迁移及限制 |
| --- | --- | --- |
| 区分目的和手段 | `ethics-primary` 卷 I，every action 与 End 讨论 | 明确一个行动追求什么，不将书中最高善直接替换为用户目标 |
| 通过行动养成倾向 | 卷 II，Virtues we get by first performing single acts；随后讨论知情、选择与稳定状态 | 实践须包含理由与纠偏，重复次数不是德性证明 |
| 相对于具体情境的中道 | 卷 II，mean relatively to ourselves 与饮食数量例子，随后无中道的行为类别 | 不取算术平均，也不能在不当行为上发明适量 |
| 审议达到目的的手段 | 卷 III，deliberate not about Ends, but Means to Ends | 在合理目标下检查可行手段；不推出任何目标都可接受 |
| 实践智慧关乎怎样生活 | 卷 VI，Practical Wisdom 定义及 Doing 与 Making 的区分 | 技术效率不等于伦理正当，不存在一本书自动计算所有选择 |

`ethics-sep` 导言解释实践智慧需要在具体场合识别理由，不能只记一般规则；这支持 Skill 的情境分析，不证明某个现代训练方案有效。

Chase 版细章编排不同于一些通行引用，正式定位采用卷加词句，未套用未经核实的细章号。卷 I 外在条件讨论带有对出身、容貌与家庭状态的历史偏见。本 Skill 保留其历史存在，拒绝将其转作现代人的价值评判。

这里没有独立现代实验验证习惯养成、心理健康或管理效果。现代流程为原创迁移；不复制受限中文译本。
