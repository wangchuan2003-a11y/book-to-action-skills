# 原创演示：向负责人报告进度风险

虚构情境：新人知道任务可能延期，却在“沉默避免得罪人”和“在群里激烈指责负责人”之间摇摆，想取中间方案，只承认一半风险。

**建议如实报告已知风险，用具体证据与可行建议控制表达方式。** 中道不是说一半真话，也不是把两种不合适的做法平均。

目的包括让团队及时调整、保护交付与公平对待有关人员。勇敢在这里可能表现为承担如实报告的不适；合宜反应还要考虑对象、时机和事实。没有证据时不把风险猜测说成必然延期。

可执行表达：“目前完成 X，Y 依赖尚未满足；按现有条件，原日期存在风险。建议先确认依赖或缩小本轮范围。”X、Y 要由真实材料填入，演示不虚构进度。

如果存在可靠的正常沟通渠道，可先向负责者说明；涉及必须及时报告的安全或合规风险，则遵循相应制度，不能以避免冲突为理由隐瞒。此次审议比较的是如何准确、及时报告，不是是否可欺骗。

## 观察与反例

记录是否清楚分开事实与预测、有关人员能否据此调整、后来事实是否支持判断。一次说清楚不证明已形成勇敢品格；后续不同情境中的稳定选择才增加证据。

若两端是零剂量和危险过量，不能拿中道推出药物剂量。涉及医疗或安全时，领域标准优先于伦理比喻。中道也不意味着永远语气温和；紧急情境可能需要直接有力地提醒。
