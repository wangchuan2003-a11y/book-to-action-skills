# 尼各马可伦理学：在具体情境中判断怎样行动

把宽泛的“成为更好的人”落到一次选择及理由。原书是伦理论证；下面的练习和复盘设计属于现代迁移，不能凭完成练习就宣称形成德性。

## 输入与阅读

找出要做的选择、受影响者、可行方案、限制与所追求的好。用户的价值取舍先如实理解，不替其指定人生终极目的。

引用和解释时读 [source-notes.md](references/source-notes.md)，应用可参考 [worked-example.md](references/worked-example.md)。[book.json](book.json) 记录覆盖，[cases.json](evals/cases.json) 用于检查行为。

## 决策方法

1. **分清目的与手段。** 说明这件事为谁、为了什么；区分工具性收益与本身值得做的活动。追问目的之间有无冲突，不无限追问到抽象人生意义。
2. **把品格词落实为行为。** 勇敢、诚实、节制等须用当前情境说明。参考卷 II，区分偶然做对、为奖励做对与理解理由后稳定选择；一次自评不能证明形成习惯。
3. **辨认过度、不足与恰当反应。** 中道相对于具体对象、时间、方式和理由，不用两极数值求平均。先检查行为种类：欺骗或侵害不能因“只做一点”而自动正当。
4. **审议可实现的手段。** 在给定合理目的下，列出自己能做且确实可行的少量方法，核查依赖与不确定性。卷 III 的手段审议不能被读成任何目的都无需道德检验。
5. **结合经验作实践判断。** 比较相关情境差异、咨询理由充分的经验判断，再选择一项动作和观察条件。能达到目标的技术巧妙，不自动等于实践智慧或值得追求的目的。

## 交付与验证

先给有条件建议，说明关键理由、中道为何不是折中，以及下一次具体如何做。用户只问概念时直接解释；明确要求练习才设计新情境。

复盘观察“在什么情况下做了什么、依据什么、后果怎样”，不把打卡次数、知识流畅或 AI 范例当成品格证据。涉及习惯效果的现代主张需要独立证据，原书不能替代。

## 边界

亚里士多德承认外在条件影响生活，但其对出身、容貌等的评价含历史偏见，不采纳为今天判断人生价值的门槛。也不将困难都归因于个人品格，忽略资源、制度或疾病。

医疗剂量、睡眠、饮食和安全阈值不能从“过与不及”求平均，须用对应专业依据。评价或批评具体行动，不凭一例给用户贴永久道德标签。引用以所读版本的卷和短语定位，不编通行细章号或页码。
