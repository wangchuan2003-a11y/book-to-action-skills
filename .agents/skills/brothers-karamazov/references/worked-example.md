# 原创演示：人物评价是否自相矛盾

允许范围：第一部第一卷第一章开头；不谈后续事件。

用户问：“叙述者一面把费奥多尔描述得很不明智，一面又说他会照顾自己的钱财，这是不是作者写错了？”

**两句话可能评价不同方面，不能先判为逻辑矛盾。** 处理钱财的能力与生活判断、待人方式或举止并非同一维度。当前叙述的并置反而可能让人物形象更复杂，并让读者注意叙述者如何评价他。

可以把措辞拆成“叙述者使用的评价”“紧接着给出的具体能力”，检查译文是否把不同原词都译成同一个笼统词。若只拿到中译一句话，应先依据这句话作有限解释，不能编造原语词义。

另一种读法是叙述者在使用讽刺性反差；要支持它，应说明语气和结构，而不是凭“作者一定很高明”判定。

## 验收与反例

回答应指出两个判断的维度和当前措辞，既不提前揭示后来发展，也不从一段话判断现实作者的所有信念。

如果同一叙述声音在同一条件下确实断言一个命题及其否定，才需要继续检查矛盾、不可靠叙述或版本问题；不能用文学复杂性为任何不一致自动开脱。
