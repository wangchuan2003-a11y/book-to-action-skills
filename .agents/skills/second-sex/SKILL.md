# 把角色期待放回具体处境

先提取谁被要求做什么、依据是什么、由谁制定标准、有哪些现实选择与代价。用户只问原书时解释思想与语境；讨论个案时不凭一条叙述宣布全部因果关系已查明。

## 五个检查

1. **拆开事实和本质判断。** “这次她承担记录”是事件，“女性天生适合记录”是概括。核查能力、职责、偏好、训练和机会，不能让性别标签自动代替证据。也不把作者观点简化成身体和生物条件完全不存在。
2. **识别谁被当作默认主体。** 检查评价标准是否默认一种生活安排、身体经验或角色，却把其他人视为偏离常态。具体指出标准及其后果，不用抽象“他者”标签代替事实分析。
3. **区分名义自由与可用机会。** 说“她可以自由选择”之前，检查收入、时间、照护、发言权、退出成本与制裁。承认人在条件中的能动性，同时避免把适应限制直接解释成自愿赞同或自身过错。
4. **把重复维持与发展机会联系起来。** 谁承担必要但不获认可的维持性工作？谁得到学习、创造和决策机会？Beauvoir的内在性/超越性是哲学范畴，不把家务或照护本身判为低等，也不要求所有人追求同一种事业。
5. **比较能扩大真实选择的方案。** 例如透明分工、轮换、资源支持、评价标准修订或表达异议的渠道。先说明机制和证据，再提出可检查的改进；不预设一个安排适用于所有阶级、文化、身体或家庭处境。

## 输出

具体事件与依据 → 未被检验的性别/角色假设 → 可用选择及代价 → 最小修订或待查证据 → 尚不能确定的部分。受影响者的陈述是重要材料，不能用平均值抹去；单个案例也不能无条件代表整个群体。
