# 原创案例：靠墙围花园

题目：有 20 米围栏，沿一面足够长的直墙围一个矩形花园。贴墙的一边不需要围栏。忽略围栏厚度，尺寸可取正实数。怎样让面积最大？

## 理解

未知量是矩形的宽和沿墙长度，目标是最大面积。令两条垂直墙的边长为 `x`，沿墙但需要围栏的另一条边长为 `y`。约束是 `2x + y = 20`，`x > 0, y > 0`，并非四面围栏的 `2x + 2y = 20`。

条件中“墙足够长”“贴墙一边不围”决定了模型，不能忽略。若题目只说“用20米围花园”而没说靠墙，需要给条件分支，不能擅自补墙。

## 计划与执行

用约束消去一个未知量：`y = 20 - 2x`，因此 `0 < x < 10`。

面积 `A = xy = x(20 - 2x) = -2x² + 20x`。配方得到 `A = 50 - 2(x - 5)²`。平方项非负，所以所有允许的 `x` 都满足 `A ≤ 50`；`x = 5` 时达到上界，且 `y = 10`。

因此两条垂直墙的边各 5 米，沿墙方向 10 米，最大面积 50 平方米。这是一般不等式与可达条件给出的证明，不是试了几个尺寸后猜测。

## 检验

代回围栏长度：`2×5 + 10 = 20` 米；面积 `5×10 = 50` 平方米；全部满足正值条件。接近 `x=0` 或 `x=10` 时面积趋近零，与图形退化相符。

独立检查：把约束写成 `(2x)+y=20`，正数乘积 `(2x)y` 在两者均为10时最大；面积是它的一半，同样得 50。若学习者尚未学过该不等式，配方法已经足够，不必增加陌生定理。

## 迁移与反例

若四边都需要围栏，约束改为 `2x+2y=20`，最优是 5 米×5 米，面积 25 平方米。原答案 5×10 不再可行。迁移的结构是“先建正确约束，再在可行域优化”，不是记住“矩形长度是宽度两倍”。

若墙只有 8 米长，还必须加 `y≤8`。用 `x=(20-y)/2` 得 `A=10y-y²/2`，在 `0<y≤8` 上递增，因此最优 `y=8, x=6`，面积 48 平方米。这个变化说明忽略约束会让原本正确的代数解变成错误建议。

现实花园还可能涉及门的位置、地块形状和法规。本例的数学最优不自动保证现实方案可实施，需要另行核对事实。
