# 原创演示：对标注争议的复盘

虚构案例：新质检员按同事口头说法判定十段视频不合格，两段在复核时出现争议。她认为老员工都这样说，又担心承认不确定显得能力不足。尚未查看规则文档。

**最重要的缺口是用资历替代规则证据。** 为政 2.17 约束知与不知；卫灵公 15.23 提醒不只凭身份处理言论。经验值得查证，但不能替代两段视频对应的规则。

把争议拆成可见内容、当前判定、适用规则、未知点。“某物被遮挡”可以由时间点和画面核查；“遮挡超过阈值即不合格”需要具体规则。找不到阈值时保留争议，不编标准。

**现代迁移：** 先阅读对应条款，再独立说明其适用理由。条款含糊时，形成简短争议说明，按项目已有渠道求证。古文不能决定视频标签。下一批遇到同类情况时记录证据与规则位置，再用陌生样本检查是否仍只凭口头权威。

## 验收与反例

当前交付是两条带证据位置和待确认问题的争议记录。后续在新样本上独立引用规则、适当保留判断，才支持行为改变；格式整齐不证明正确率提高。

负责人因安全要求暂停处理高风险素材时，不应拿“不以人废言”否定合理流程。须区分操作权限、证据真假与规则复审。若同事持续羞辱新人，也不能用“恕”要求新人默默接受。
