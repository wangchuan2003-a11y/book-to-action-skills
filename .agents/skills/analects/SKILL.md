# 论语：把学、思与改过连接起来

用有限、已核实的篇章检查学习或人际判断。原书提供伦理与修身观念；下面的工作步骤是本项目的现代迁移，效果需要现实观察。

## 定位问题

从用户叙述找出一次具体学习活动、争议或失误，明确原本要做到什么、实际发生什么。材料不足时做有限判断或标明假设，不把问题自动解释成用户不够自律。

解释篇章或引用时读 [source-notes.md](references/source-notes.md)。行动复盘可参考 [worked-example.md](references/worked-example.md)。书目与已读范围见 [book.json](book.json)，检查场景见 [cases.json](evals/cases.json)。

## 五个检查

按问题选用，不强迫每次完成全部检查。

- **学与思相互校正（2.15）。** 列出实际接触的材料与自己的推断。只有复述时，补一个解释或应用；只有空想时，补必要材料。书中没有规定现代间隔重复或检索练习的参数。
- **知道与不知道分开（2.17）。** 把关键判断分成有证据、尚存争议、缺少信息。给重要未知指定可取得的证据，不只说保持谦逊。
- **评价理由而不只看身份（15.23）。** 职位、表达能力或声誉不是某个主张真假的充分证据。可信记录可以影响审查优先级，但不能替代内容核查。
- **以恕检验施加的负担（15.24）。** 说明对方将承受什么，检查是否将自己不愿承受的待遇强加给对方。再核实对方的实际需求，不把自己的偏好当作对方同意。
- **让改过体现为行为（15.30）。** 找到可改变的行为或决策环节，定义下一次如何做，以及观察到什么才算改进。道歉、总结与承诺不能单独证明问题已修正。

## 输出

先指出最重要的一个判断或行动缺口，说明对应篇章，再给具体调整与观察方法。用户只问原文含义时直接解释，附语境与分歧，不强制布置作业。用户明确要求练习时才用陌生案例检验迁移。

## 语境与边界

《论语》来自长期传承的孔子及其弟子言行材料，不把每章当作独立、无争议的现代定义。篇章号以本 Skill 的 ctext 来源为准；跨版本须核对，不能凭记忆制造页码。

“恕”不要求容忍伤害，“改过”不能变成对受害者的指责。古代尊卑、家族与礼制语境不能自动决定现代职业关系。发现压制、欺骗或安全问题时，按事实讨论责任与支持，不用经典要求服从。

现代学习效果没有独立研究或实际结果时，应保持待验证。不要把现代教学术语倒写成孔子已经提出的完整科学理论。
