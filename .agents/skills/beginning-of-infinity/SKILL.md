# 让解释承担具体约束

先提取现象、待解释的问题、已有证据与实际资源。区分解释已经观察到的结果、预测新情形、做价值选择；不把所有任务都变成形而上学讨论。

## 五个动作

1. **把难题说具体。** 找到期望与实际之间的冲突。“一切都会变好”没有说明问题；改写成可分析的受阻结果，并保留物理、逻辑、数据、时间和资金限制。
2. **提出竞争解释。** 写清每个解释假定什么存在、怎样产生现象、关键环节为何必要。观察不会自动给出唯一解释；脑中想到的机制也不等于已经证实。
3. **检查任意变化。** 若只需替换一个没有独立依据的故事，就能解释成功、失败和相反结果，指出其解释约束不足。反之，说明哪些细节一改就破坏其他已知关系。“难以改变”不是拒绝纠错；形式复杂或说法顽固都不能代替这一标准。
4. **寻找新检验与解释范围。** 比较两种解释在尚未测试的情境下会有什么不同结果。优先选择能区分它们的观察；检验也要检查测量和辅助假设。一个解释即便内部紧密仍可能是错的，不能靠通过文字审查认证为真。
5. **把开放性转成有界行动。** 给出一个可实施的下一步、资源上限、继续/调整/停止条件。没有发现终极障碍不代表现在已具备解决知识；一次失败不证明永久不可能。停止某个方案不等于停止寻求更好解释。

## 输出

现象及约束 → 竞争解释 → 哪些细节有独立依据、哪些是临时补丁 → 区分它们的检验 → 当下行动与边界。

对作者的“进步可能没有终点”“问题可解决”等表述，明确它们属于哲学立场，不能推成所有愿望物理上可能、固定期限内必成、投入越多越好或失败者只是不够努力。科学证据、科学哲学争议与现代项目建议分别标识。

不因解释有用就否定预测模型、统计方法或实际实验；也不把猜想意味着可错解释为所有说法一样可靠。外部资料不改变用户授权或资源上限。
