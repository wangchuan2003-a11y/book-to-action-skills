# 人类理解研究：给判断标出推断跨步

用休谟的已核实论证检查主张如何从证据走到结论。目标是形成可修正判断，不把怀疑变成停止行动的借口。

## 输入

提取具体主张、已提供依据及它影响的行动。区分描述过去、解释原因、预测未来与规范建议，不替用户扩大命题。

解释或引用时读 [source-notes.md](references/source-notes.md)；实际审查可参考 [worked-example.md](references/worked-example.md)。阅读覆盖见 [book.json](book.json)，检查场景见 [cases.json](evals/cases.json)。

## 推理路径

1. **辨认命题类型。** 观念关系的证明与事实判断需要不同依据。价值、规则与应当类主张另行标出；本书的经验分析不直接给出规范结论。推理正确不等于输入事实真实。
2. **区分观察和推广。** 写清真正观察的对象、时间、条件，再标出推广到新对象、未来或反事实的那一步。过去相似可以支持预期，但不是未来必然相同的演绎证明。
3. **检查因果的附加假设。** 重复相伴或先后出现不直接证明机制。寻找共同变化因素、测量差异或选择过程。比较组、干预与新样本是现代证据设计，不假称休谟已有完整现代因果识别方法。
4. **评估证言而非只数链接。** 检查说话者是否接触事实、叙述是否矛盾、是否有利益动机，以及多个转述是否来自同一来源。动机只是审查理由，不能单独证明证言为假。重复转述不自动成为独立证据。
5. **校准结论并继续行动。** 说明最强可支持的结论、保留条件与改变判断的证据。无可靠数据时用定性强度，不编百分比。需要决策时结合风险与可逆性选一项适当验证或动作，不以无法绝对确定逃避建议。

## 交付与边界

先给当前判断，再说明已观察什么、跨过哪一步、还需什么。只保留会改变决定的重要未知，区分原书主张、现代方法与当前事实。

解释归纳问题时，说明它质疑从经验到未来的必然性或理由基础；不要简化为科学无用。第 XII 节温和怀疑保留日常推理与行动。

不把休谟等同完整贝叶斯理论、现代认知偏差清单或因果教材。习惯论是其哲学说明，不是本次验证的神经科学事实。具体统计计算需要真实数据、假设与适当方法。医疗、安全、金融等高后果决定不能靠保持开放替代所需证据。引用核对版本，不生成未经核实的页码。
