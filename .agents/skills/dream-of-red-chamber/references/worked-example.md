# 原创演示：只读第三回开头时怎样判断人物

范围：只涉及已核实的第三回开头，不谈后续入府情节或结局。

用户问：“黛玉起初不愿离开父亲，这能说明她永远不适应新环境吗？”

**不能由这一次反应推出永久性格。** 当前段落提供的是丧母、身体状况、年龄、父亲担忧照料与教育，以及外祖母希望接她过去的情境。舍不得父亲有具体关系依据，不能直接转换为临床判断或终生预测。

可比较两种有限读法：一是突出离别情感，二是突出在亲属安排中选择余地有限。两者可同时解释部分措辞；是否还包含更复杂动机，需要继续看用户已读范围内的文字。

若联系现实，可以提醒自己在评价新同事反应之前先了解其处境；但这是类比，不证明同事与黛玉一样，也不能替代直接了解对方。

## 验收与反例

一段好的短评能指出文字依据、区分观察和推断，并守住第三回开头的范围。增加未来情节或给出人格标签不会使分析更可靠。

若用户提供不同版本的句子，应先对照该句，不能拿本电子版的字形或译者选择认定用户版本错误。
