# 红楼梦：让人物和叙述层次留在文字里

帮助用户细读或比较解释，不把小说人物压成性格标签或处世公式。

## 阅读范围先行

优先使用用户说明的版本、回目、已读进度与所给文字。明确表示不剧透时，连后续人物结局、身份揭示、关系走向与“后来会证明”式暗示也不要带入。范围不明时只用用户提供片段或无情节的阅读方法，不默认全书可谈。

本 Skill 实际读取范围见 [book.json](book.json)。引用或版本判断读 [source-notes.md](references/source-notes.md)；演示见 [worked-example.md](references/worked-example.md)，仅在其回目不超出用户范围时使用。[cases.json](evals/cases.json) 供行为检查。

## 五个细读动作

1. **先标出谁在说。** 区分现实作者、开篇的叙述自述、石头与传抄框架、故事叙述者及具体人物。文中出现作者姓名仍可能是框架的一部分，不能直接等同历史证明。
2. **把判断落回文字。** 将人物做了什么、他人怎样评价、读者推断的动机分开。每个重要判断给当前范围内的动作、措辞或叙述依据；找不到便降低结论强度。
3. **重建关系与处境。** 检查亲属位置、依附关系、礼仪、利益及当前所知信息。第三回开头可示范如何把人物行动放回情境，但不能由一个情境推出永久人格。
4. **容纳至少一种有根据的不同读法。** 比较两种读法各自解释了什么、遗漏什么，保留语言的反讽、含混与情感张力。不同读法仍需证据，不等于任何解释都成立。
5. **核对版本后再推广。** 对同一回目或语句先说明底本、标点与译名差异。用小说联系现实时明确相似处与差异，把它作为理解的类比，不能用来诊断同事或保证职场效果。

## 交付

先回答用户眼前问题，用少量短引或转述支持，然后说明一种必要的解释保留。普通讲解不强迫课程或测验；用户要求写作时可以形成有证据的短评。

前八十回与后四十回不应无区别地归于曹雪芹。1791年120回刊本由程伟元、高鹗整理刊行，后40回写作归属仍有争论；不要把“高鹗独立续写”或“完整原稿已找到”说成无争议定论。本项目未校勘各底本，页码与异文须依据实际版本。

人物的历史性别观念、身份评价或家族规范不自动成为作者命令，也不是当代人的行为义务。不要凭小说作医学诊断或将复杂经历归为单一性格缺陷。
