# 原创演示：叙述里的作者与书目作者

允许范围：用户已读到第二部第二章。本例不谈此后情节。

用户问：“人物说故事作者叫 Cide Hamete，书的作者怎么又是塞万提斯？”

**这是不同层次的作者身份。** 现实出版作品由 Cervantes 写作；小说内部还设置故事来源、史家与转述的说法。叙述使用这些中介不等于书目需要换名。

当前片段中，Sancho 转述消息，人物对名称作出回应。阅读时可以分别记“现实书目署名”“故事里声称的来源”“谁转述给谁”，再检查文字是否把某条消息当作可靠知识，还是让读者注意转述的偏差。

这一安排可以产生幽默，也使故事如何被讲述成为故事的一部分。该解释由当前细节支持，不需要提前说明人物此后的命运。

## 验收与反例

合格回答能区分三层身份，并指出当前消息的转述性质；不能把虚构史家当历史上实际完成该小说的人，也不能把角色发言直接列为作者信念。

若用户只读第一部第一章，则不用此例；可以仅解释作者、叙述者和人物的一般区别，再分析其提供的开篇句子。不能为了讲清概念而牺牲不剧透承诺。
