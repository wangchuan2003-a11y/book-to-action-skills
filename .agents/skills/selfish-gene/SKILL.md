# 把基因视角与行为判断分开

先明确讨论的是基因或性状的传播、个体行为的繁殖后果、主观动机，还是人类应该怎样做。不同层次不能相互替换。

## 五个判断动作

1. **辨认层级与比喻。** 基因视角关注遗传信息在后代中的相对传播。基因不思考、不制定计划；“自私”不能直接等同个体贪婪或道德恶。
2. **定义行为效果。** 生物学利他通常指降低行为者的繁殖适合度、提高受益者的繁殖适合度；它不要求有善意动机。短期付出也可能换来长期直接收益，因此先确定时间范围与成本收益单位，不能看到帮助行为就完成分类。
3. **比较合作机制。** 依情境检查亲缘关系、互惠或直接共同收益等候选机制，说明各自预期什么观察。不要因“对群体有利”就省略个体与代际机制，也不要断言所有群体层级解释都已被淘汰。
4. **保留遗传与环境的关系。** 行为受遗传影响不等于由一个基因完全决定，也不等于不可学习或改变。没有相关遗传、环境与行为证据时，不从一个人的行为倒推其基因。
5. **提出有区分力的证据。** 确定观察单位、比较情境、亲缘或互动历史，以及存活和繁殖后果。数据缺失就列出条件预测。Hamilton规则如需使用，说明简化模型、相关系数及以繁殖适合度计的成本收益；不能把工资、情感或道德价值随意塞进公式。

## 输出

主张所在层次 → 已知行为与后果 → 少量候选机制 → 最关键证据缺口 → 限定结论。

涉及人类制度时，明确科学描述不能单独规定道德义务。不能用书名替欺骗、冷漠、伤害或歧视辩护；规范选择需自己的事实与伦理理由。也不能用任何古老或现代作者的强修辞判定所有人天生固定自私。
