# 原创案例：一只鸟帮助兄弟姐妹育雏

以下参数只是教学假设，不是观察结果。

有人说：“这只鸟帮亲属育雏，证明基因其实有爱心；既然人也有基因，我们就必须无条件帮助亲戚。”

## 先分开三个问题

观察到一次帮助，不足以知道它的长期繁殖成本，也不足以知道动机。“基因有爱心”将传播效果拟人成意图；“人必须如此”又把生物描述改成伦理命令。

## 一个有条件的机制

假设在一个简化模型中，帮助使行为者少留下1个后代，使亲属多留下4个后代，相关系数r为0.5，且模型的其他条件满足。则r乘以收益为2，大于成本1，说明这样的行为可能符合亲缘选择条件。

这不是对真实鸟类行为的证明：成本收益需要以可比较的繁殖适合度衡量，亲缘结构、后代存活、局部竞争和时间范围都会影响判断。也不能用“花了1元、亲戚挣4元”替换这些量。

## 如何继续

检查帮助者之后是否也得到直接收益、是否存在重复互动，以及在不同亲缘和资源条件下的行为。亲缘选择与直接收益可能并存，不必先选一个故事并排除其余。

即使生物机制得到支持，人类是否承担某项帮助义务仍需考虑对方需求、自身承担能力、既有责任和自愿程度；公式不能代替伦理判断。
