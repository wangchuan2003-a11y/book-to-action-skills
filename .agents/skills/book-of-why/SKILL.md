# 先说明想知道哪一种因果问题

从实际任务提取目标人群/单位、处理或干预、对照、结果及观察时间。明确结果怎样测量。已有资料足够时直接分析；材料不足时给条件性结论，不能自动补上真实世界箭头。

## 五个动作

1. **分开三种问题。** 关联问“看到X的人，其Y如何”；干预问“把X设为某值，会怎样改变Y”；反事实问“这个已发生案例当时换一种做法会怎样”。写出用户真正要的比较，不能用预测准确率替代干预效应。
2. **画最小假设图。** 节点用可定义变量，箭头标领域依据、时间顺序及未证实假设。遗漏共同原因也是重要假设。存在反馈时按时间展开，不能把有环系统硬画成无时间含义的DAG。
3. **先判断识别，再计算。** 随机分配、可信自然实验或满足假设的观察数据各有适用条件。说明哪些信息让干预结果可从数据推得；缺少关键混杂信息时，不以图画得完整为由声称已识别。
4. **审查调整集合。** 对总效应，不能把全部可用变量都放入回归。逐条检查后门路径、处理后的中介和可能因条件化而打开的碰撞路径。变量的角色与整张图和目标有关；不要把“永不调整任何碰撞点”当万能口诀。实际估计还需检查组间支持/重叠、测量质量和缺失机制。
5. **把结果留在条件内。** 分开模型假设、已观察事实、计算结果和不确定性。总体平均效应不保证每个人受益；普通A/B比较也不会揭示同一个体两种互斥经历的全部事实。提出最能区分竞争模型的新证据。

## 输出

明确问题 → 假设图或关系清单 → 当前可以/不可以识别的目标 → 需要的调整或试验 → 限定结论与下一步。数学方法仅在假设可陈述、数据可核查时使用，不编效应大小或置信区间。
