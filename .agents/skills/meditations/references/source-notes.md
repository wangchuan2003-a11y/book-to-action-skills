# 来源与思想边界

访问日期：2026-09-07。`marcus-primary` 与 `marcus-sep` 均 HTTP 200，实际读取范围见 book.json。

`marcus-sep` 说明作者为公元2世纪罗马皇帝、文本写给自己，至少部分写于晚年军事行动期间。网页列表把作品概括到某一年，不足以证明整书在那一年一次写成。

正式原文采用 Internet Classics Archive 的 George Long 全文；其卷标题为 BOOK TWO 等。研究时另见 Gutenberg #2680 的早期译本编排不同，因此不把两者的细段号混用。这里只采用实际核实的卷与短语。

| 原则 | 原文位置 | 现代迁移与限制 |
| --- | --- | --- |
| 人际困难中仍考虑合作 | `marcus-primary` 卷 II 开头 Begin the morning | 预想困难并选择回应，不预先把所有人认定恶意 |
| 判断可以检视 | 卷 IV，Take away thy opinion | 区分事实与追加解释，不能说真实伤害都是想出来的 |
| 允许内在整理 | 卷 IV，Men seek retreats for themselves | 短暂休整以重回事务，不替代睡眠、医疗或现实支持 |
| 不复制不当行为 | 卷 VI，best way of avenging thyself | 不以羞辱回应羞辱；维权并不自动等同报复 |
| 防止身份腐蚀判断 | 卷 VI，not made into a Caesar | 检查职位和名声是否阻碍纠错，不消灭合理自尊 |

`marcus-sep` 第 4.2 节讨论 impression、assent 与 judgment，说明“抹去印象”的意思存在解释问题。印象的发生不能简单理解为个人随意选择；现代回复不能要求用户立刻清空情绪。

古代“只有德性才是善”的主张有其伦理和宇宙观前提，不等于临床结论。原文有关于死亡和退出生命的陈述，作为历史文本可解释，但本 Skill 不把它们转成自伤建议或对他人的命令。没有引入现代治疗效果研究。中文为原创解释，不复制现代译本。
