# 原创演示：收到尖锐的工作反馈

虚构情境：同事指出报告中一项数据错误，并在群里说“你根本不适合这份工作”。用户因此认为整个职业生涯已失败，想立刻发一段羞辱对方的回复。

**先把可改的问题与越界评价分开。** 报告数据是否错误可以核查；一句人格判断不能证明职业生涯失败。公开羞辱本身也不因作者强调判断而变得合理。

可以先暂停发送，核实数据并保存原始记录。若确有错误，承认具体错误、说明修正；对人格攻击说明希望讨论具体工作事实。暂停是为选择回应，不是要求当场不难过。

回应示例：“这项数据我正在核对；如有错误会说明更正。请具体指出报告问题，避免对个人能力作笼统评价。”实际内容应按真实关系和组织流程调整。

若攻击反复发生，可以通过已有支持或投诉渠道处理。避免反向羞辱与维护边界能够同时成立；不能把投诉一概叫作报复。

## 验收与反例

可观察结果是数据得到核查、回应准确、边界明确；情绪仍然难受不代表练习失败或品格不足。是否改善工作关系须后续观察。

如果用户已连续失眠或承受严重压力，自省只能是可选辅助，应取得适当现实支持，不能说“想开就好”。如果数据没错，也不应为了显得平静就虚假认错。
