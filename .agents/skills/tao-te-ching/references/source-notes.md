# 来源、章号与解释范围

访问日期：2026-09-07。`dao-primary`、`dao-sep` 与 `dao-legge` 均 HTTP 200，已读范围见 book.json。

`dao-sep` 介绍老子传记与文本形成的多种理解，并说明马王堆、郭店材料与传世本的文本史关系。传统老子归属不等于已证明由一个人在确定年份一次写成；最终编纂也不应假定为随机拼凑。

| 原则 | 正式中文位置 | 现代迁移的界限 |
| --- | --- | --- |
| 名目不能穷尽所指 | `dao-primary` 第 1 章，道可道与名可名 | 检查标签与实际，是现代类比，不是否定一切定义 |
| 无为与日损 | 第 48 章；`dao-legge` 第 37、48 章交叉读到 non-action | 检查多余干预，不取消必要行动 |
| 完成事务而不占据功劳中心 | `dao-primary` 第 17 章，功成事遂与我自然 | 促进自主完成，不能用不露面掩盖责任 |
| 早期处理并慎终 | 第 64 章，未兆、始于足下与慎终如始 | 前期和收尾各设适当检查，不保证零失败 |
| 慈、俭、不敢为天下先 | 第 67 章，三宝 | 检查对人、资源与争胜的取舍，不等于永远退让或削减安全投入 |

`dao-sep` 的 Naturalness and Nonaction 明确说明 wuwei 不等于 total inaction，并介绍不同译法。`dao-legge` 的括注和译词体现译者解释；与 ctext 的相关英文呈现不能算作两份独立经验支持。

正式章号按 ctext 本页的传世文本排列；不声称帛书、郭店材料与之逐章一致。第 1 章的断句和第 17 章的含义也不能仅以某英文译法定于一尊。

现代减流程试验和验收办法由本项目设计，没有现代实证证明所有组织都因少干预而更好。古代养生、政治与宗教语境不能取代今天的医疗或制度证据。中文解释为原创，不复制受限现代译注。
