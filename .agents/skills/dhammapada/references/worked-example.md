# 原创案例：受到指责后想公开羞辱对方

用户主动请求用《法句经》反思：同事在群里错误地归责于自己，用户准备回一条带人身攻击的话。以下不是实际发送记录。

先保留事件事实：指责是否错误，要核对原记录。愤怒可以理解，反思自己的回应不等于承认对方说得对。若存在持续骚扰或风险，应优先保护自己并使用适当渠道。

依据第1品3—6偈，可以观察重复“他羞辱我，所以我要让他更难堪”的念头是否把目标从澄清事实改成报复。这个观察不要求忘记、删除证据或强迫宽恕。

依据第17品的自制与真实言语方向，先保留未发送的草稿，把攻击性判断和可核查事实分开。例如拟稿：“这项任务的交接记录显示我在周二提交，剩余审批由另一个环节处理。请依据记录更正责任说明。”日期与职责只有真实材料支持时才能写入。

这是候选表达，不是要求立即发送；沟通授权和具体风险仍需遵守。必要时可以通过适当管理或申诉渠道处理，不必在公开群里争辩。

第1品19—20提醒把原则落实为行为：实际检查的是是否陈述真实事实、是否减少可避免的伤害、是否保留边界。会复述经文或由AI写好回复，不能证明用户已经获得修行成就。

反例：如果对方威胁人身安全，不能要求用户“先消除敌意才求助”。如果用户持续受到强烈心理困扰，本例也不能替代合适的支持或专业照护。
