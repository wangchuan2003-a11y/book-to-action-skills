# 采用的巴利本与选偈

访问日期：2026-09-07。仅原创释义，不复制全经。

## DHP-1：译者说明

[Thanissaro Bhikkhu导言](https://www.accesstoinsight.org/tipitaka/kn/dhp/dhp.intro.than.html) 已读取前言与导言开头，前言署1997年12月。译者将该书描述为传统归于佛陀的偈颂集，并区分外部历史阅读与作为个人实践指南的阅读。本版本有自己的术语选择，例如heart、stress、Unbinding，不擅自当成所有中译本的固定对应。

所见书目涉及巴利、犍陀罗、Patna与中文传统。本项目只采用此巴利译本，不声称这些传统的偈数、篇章与解释相同；未给古代编集强行指定单一年份。

## DHP-2：第1品

[Yamakavagga](https://www.accesstoinsight.org/tipitaka/kn/dhp/dhp.01.than.html) 1—20偈已读。3—6偈讨论反复执取受辱叙事与敌意，19—20偈对照背诵与实践。对当事人的保护、保留证据与合法求助，是本项目的现实边界，不把减少敌意解释为默许侵害。

1—2及15—18偈包含心念、行为、幸福痛苦和来世的宗教论述。它们可用于介绍传统观点，不能证明某个受害者因思想不善而应得伤害。

## DHP-3：第17品

[Kodhavagga](https://www.accesstoinsight.org/tipitaka/kn/dhp/dhp.17.than.html) 221—234偈已读。222及231—234偈支持关注反应的自制，223—224涉及非敌意与真实言语，227—230涉及赞扬和批评。经文中的天界、解脱等说明保留为宗教内容，不改写成科学机制。

五项操作的对应：区分事实与下一步是项目设计；觉察持续敌意来自DHP-2；审慎反应及诚实来自DHP-3；实践与背诵之别来自DHP-2；不追求所有人赞同的反思取自DHP-3。暂停发送、核对事实和事后反馈不是作者原有的现代沟通协议。
