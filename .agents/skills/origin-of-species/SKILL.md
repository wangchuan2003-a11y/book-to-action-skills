# 检查一个进化解释

先确定用户在问历史原书、现代生物机制，还是把进化借来解释非生物问题。三者明确分开。以1859初版相关段落为历史来源，以现代教学资料补足概念，不能把现代基因知识倒写成 Darwin 当时已经掌握的内容。

## 五个判断动作

1. **定位发生变化的单位。** 写明种群、性状、环境和代际跨度。个体变强、学习新技能、换季变色，不自动等于种群发生遗传演化；区分表型可塑性与跨代频率变化。
2. **核对条件链。** 是否存在性状变异？差异能否遗传？这些差异在当前环境下是否关联留下后代的差别？缺一项就指出证据缺口，不把“后来更多”直接归因于选择。
3. **把适合放回环境。** 适合度涉及繁殖贡献，并不等于体力、道德优越或绝对先进。竞争、寄生、合作和对物理条件的依赖都可能重要；“生存斗争”不能窄化为互相残杀。
4. **比较其他解释。** 频率变化可能还涉及漂变、迁移、突变或测量和抽样变化。自然选择不预先知道目标，也不能因为某种特征有用就断言它必然为该用途演化。
5. **提出能区分解释的观察。** 给出最低限度需要的跨代数据、亲代后代关系、环境或繁殖记录。允许用已有资料或无伤害教学模拟说明；没有真实数据时只给条件预测，不伪称做过实验。

## 交付

用“观察 → 候选机制及必要条件 → 缺失证据 → 区分解释的下一步 → 结论边界”回应。定义每个关键量的单位；数据不足不编造遗传率、选择系数或代数。

非生物类比只在用户明确需要时使用，并逐项说明什么对应变异、保留、复制和选择环境，哪里没有对应关系。人为优化有目标与设计者，不能直接等同无预见的自然选择。员工、民族或个人的权利与价值不由所谓适合度排序。

[来源说明](references/source-notes.md)定位历史文本与现代补充；解释出处时读取。[原创案例](references/worked-example.md)演示植物耐旱叙述的几种解释。

只有观察结果支持的部分才写成结论；书中权威和外部资料不授权采集样本、操纵生态或改变人员制度。
